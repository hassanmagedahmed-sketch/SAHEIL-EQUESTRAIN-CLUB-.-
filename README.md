# Saheil Equestrian Club — Design 03

## Publish with GitHub Pages
1. Create a **Public** repository on GitHub.
2. Upload the **contents of this folder** (not the enclosing folder), including `index.html` and the `assets/` folder, to the repository root.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Wait for deployment and open the `Visit site` link shown on the Pages settings screen.

All local page and asset links in this bundle have been checked. This is a static site: Sign Up/Login demo data is saved in the visitor's browser; there is no secure shared account database or real SMS verification. WhatsApp booking opens a prepared message for the visitor to send.


Navigation styling update: dedicated page links such as Contact Us, Privacy Policy, Terms & Conditions, Customization, Location, Login, and Sign Up are outlined as clickable buttons and show a small ↗ arrow. Section links such as Experiences and About remain in-page anchors.
